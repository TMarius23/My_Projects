Downloader HTTP
Se introduce un URL in consola și se descarca pagina HTML.
Se poate observa lucrul cu protocoalele de comunicare,
cu socket-uri, parsari, comprimari si prelucrarea si valorificarea datelor
Este un proiect respectabil care te ajuta sa inveti partea de comunicare
si preluarea datelor de pe un server
Intelegerea conceptelor http/ https si a TCP, TLS, OpenSSL

Pasi facuti:
1.Parsezi URL → găsești host, port, path.
2.Faci getaddrinfo() pentru a afla IP-ul.
3.Creezi un socket().
4.Faci connect() la server.
5.Trimiți cererea HTTP (cu send()).
6.Primești răspuns (cu recv()).
7.Desparți antetul de corp (\r\n\r\n).
8.În funcție de antete:
    citești tot corpul (cu Content-Length),
    citești bucăți (chunked),
    citești până serverul închide conexiunea.
9.Afișezi sau salvezi rezultatul.
